# 灵灵运营管理后台原型

HaloBot 灵灵运营管理后台的可交互原型，包含培训项目、课程内容、题库、考试配置以及学习成绩管理。

## 在线发布

项目通过 GitLab Pages 自动发布。推送到 `main` 分支后，GitLab CI/CD 会将静态文件复制到 `public/` 并更新预览站点。

## 本地预览

在项目目录启动任意静态文件服务器，例如：

```bash
python -m http.server 18121
```

然后访问 `http://127.0.0.1:18121/`。

## 数据说明

原型数据保存在浏览器 `localStorage` 中，不同浏览器之间不共享，适合产品演示和交互评审。
